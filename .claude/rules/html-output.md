# HTML Output (`index.html`)

- Generated by `render.py` from `templates/index.html.j2` with jinja2 autoescaping on.
- Single static file that opens in any browser. All data embedded as one JSON blob (`<script type="application/json" id="report-data">`); no fetches.
- Chart.js from a pinned CDN URL: `https://cdn.jsdelivr.net/npm/chart.js@4.4.1/dist/chart.umd.min.js`. No other external scripts.
- Contains only anonymized labels and computed numbers, never raw input text.

## Page sections (in order)

1. Header: "Your Net Worth Report", date generated, disclaimer
2. KPI tiles: net worth, grade (A–F), age percentile ("Top 18%"), credit tier, debt-to-asset ratio
3. Verdict (honest paragraphs)
4. Breakdown: assets and debts
5. History and projections
6. Age comparison
7. State comparison
8. Credit score
9. Income and savings rate (only if data given)
10. Assumptions used (table: value + source)
11. Final summary
12. Suggestions (ranked)
13. Footer: data sources, "not financial advice" disclaimer

## Charts

| Chart | Built with | Shows |
|---|---|---|
| Assets and debts by category | Chart.js horizontal bars (assets slot 1, debts slot 2) | Totals per category; asset bars carry "· NN%" share labels (this replaces a separate mix chart: a 2-slice donut is an anti-pattern and a second categorical palette clashed with assets/debts colors) |
| Net worth history | Chart.js line + 10% wash | Every history point; quarter/half-year/year ticks by span |
| Projection | Chart.js line | History (solid), expected (dashed), conservative–optimistic band, default-assumptions line (slot 2) when assumptions changed; end labels drop when they'd collide |
| Projection milestones | HTML tiles | Expected at 5/10/15/20 years, today's dollars, range |
| Where you fall (age) | Chart.js bars, emphasis | 10/25/50/75/90th percentiles (+ next tier above if past 90th) in gray, you in blue |
| Median by age | Chart.js columns, emphasis | Median per bracket, your bracket in blue, a "You" reference line |
| State comparison | Chart.js bars, emphasis | You, state median, U.S. median, you at national prices |
| Credit score | HTML meter | 300–850 track in the validated ordinal blue ramp, your marker(s), state/U.S. average ticks, tier legend below |
| Income vs. Δ net worth | Chart.js grouped bars, one $ axis | Only when income and history overlap; savings rate in the table (never a second axis) |
| Score breakdown | HTML bars | Each component, status color + icon + word (Strong/Needs work/Weak) |
| Who owns what (couples) | Chart.js grouped bars | Assets/debts by Partner 1, Partner 2, Joint |

Hide any chart whose data is missing, with a one-line note saying why. Every chart has a "Show table" twin; if Chart.js can't load, the page adds `no-charts`, opens every table, and shows a note.

## Design

- Colors from the dataviz reference palette as CSS variables, light + dark, swapped under `prefers-color-scheme` and `[data-theme]`; Chart.js reads them at draw time and rebuilds on theme change. Palette slots 1–6 and the credit ramp were run through the dataviz validator (both modes pass; light slots 3–5 are < 3:1, so they always ship with labels/tables).
- Thin marks: bars ≤ 24px with 4px rounded ends square at the baseline, 2px lines, hairline solid gridlines. Text never wears series colors.
- Status colors only for status (score bars, findings), always with an icon + word.
- Mobile: verified with no horizontal overflow at 360 and 390px (grid columns use `minmax(0, 1fr)`, long URLs wrap, edge labels anchor inward). Headless Chrome can't lay out below 500px, so check phone widths in a 390px iframe.
- Money axis labels use the compact money format (`$30K`, `$1.2M`).
- Every chart has a title and a one-sentence plain-English takeaway under it.
- `render.py` builds a view model; the template never parses report text.
